Cloudflared 隧道设置

所有选项写入 /etc/config/cloudflared，点击「保存并应用」后由 procd 自动重载服务。

基本设置

开启
Token：Zero Trust 远程管理；config.yml：本地管理，需要证书 JSON 与 ingress 规则。

升级设置

开启
默认每天 03:30，任务会先对比版本再决定是否下载。
GitHub Release CDN 不通时填写镜像前缀；版本信息与 SHA-256 仍取自官方 API。
开启
开启

隧道 Token

已保存 Token（0600，仅 root 可读）。粘贴新值将覆盖。

Token 不写入 UCI，也不出现在进程命令行（cloudflared ≥ 2025.4.0 使用 --token-file）。

本地 config.yml

仅在「config.yml（本地管理）」模式下生效。

升级

从 Cloudflare 官方 GitHub Release 下载对应架构的 cloudflared，校验 SHA-256 后原子替换，并保留上一版本以便回滚。
